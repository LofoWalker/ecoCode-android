Using image formats like .png, .jpg, .jpeg, or .gif in the /res/drawable/ folder instead of .webp leads to larger APK sizes and less efficient compression. WebP format, developed by Google, provides better compression with no visible quality loss and is therefore recommended for Android drawable resources. This rule detects non-WebP image formats in /res/drawable/ and encourages conversion to WebP early in development.

Noncompliant Code Example

Usage of non-WebP images in drawable folder: 
res/drawable/logo.png
res/drawable/background.jpg
res/drawable/icon.gif

Compliant Code Example

Usage of WebP images in drawable folder: 
res/drawable/logo.webp
res/drawable/background.webp
res/drawable/icon.webp
